# Campus Hub - Mobile Application

React Native және TypeScript көмегімен жасалған мобильді қосымша. 

## Зертханалық жұмыс 6: Жоба құрылымын рефакторингтеу және Git-пен жұмыс

### Жоба құрылымы:
- `src/types/` — TypeScript типтері мен интерфейстері
- `src/data/` — Деректер мен массивтер
- `src/components/` — Қайта пайдаланылатын компоненттер (SectionTitle, ServiceCard, EmptyState, ProfileMenuItem)
- `src/screens/` — Қосымша экрандары (Home, Services, Profile, Details)
- `src/styles/` — Ортақ түстер мен стильдер (theme.ts)
